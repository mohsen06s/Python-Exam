    شرط‌ها؛ لحظهٔ تصمیم

    برنامه‌ها همیشه یک مسیر ثابت را طی نمی‌کنند. با شرط‌ها می‌توانیم براساس اطلاعات، مسیر مناسب را انتخاب کنیم.

    if else elif Indentation and / or / not
    در این بخش ساختار if دو مسیر با else چند مسیر با elif شرط‌های ترکیبی پروژهٔ پایان بخش
    اگر باران ببارد، چتر برمی‌دارم. اگر نبارد، بدون چتر بیرون می‌روم.

    این تصمیم روزمره، همان ایده‌ای است که با if و else به برنامه یاد می‌دهیم.

    ۱. شرط چیست؟

    شرط، پرسشی است که پاسخ آن معمولاً «درست» یا «نادرست» است. مثلاً «آیا نمرهٔ دانش‌آموز دست‌کم ۱۰ است؟». برنامه نتیجهٔ این پرسش را بررسی می‌کند و بر اساس آن تصمیم می‌گیرد.

    پرسش برنامه آیا سن دست‌کم ۱۳ است؟
    اگر پاسخ True باشد پیام اجازهٔ ورود
    اگر پاسخ False باشد پیام عدم اجازهٔ ورود

    ۲. ساختار if

    بعد از if یک شرط می‌نویسیم. اگر شرط درست باشد، دستورِ داخل آن اجرا می‌شود.

    first_condition.py
    age = 15

if age >= 13:
    print("You can enter.")
    خروجی 
    You can enter.

    ۳. شرط چگونه کار می‌کند؟

    در مثال قبل، پایتون عبارت age >= 13 را بررسی می‌کند. چون ۱۵ بزرگ‌تر از ۱۳ است، نتیجه True می‌شود و دستور چاپ اجرا خواهد شد.

    age = 15 ← 15 >= 13 ← True ← اجرای دستور

    ۴. علامت دونقطه

    پس از شرط، علامت : می‌آید. این علامت به پایتون می‌گوید که دستورهای مربوط به آن شرط در ادامه قرار دارند.

    colon.py
    if age >= 13:
    print("Allowed")
    دقت کن

    این قطعه‌کد فرض می‌کند متغیر age پیش از اجرای شرط، مقدار گرفته باشد؛ مثلاً age = 15.

    ۵. تورفتگی یا Indentation

    دستورهایی که باید در صورت درست‌بودن شرط اجرا شوند، کمی جلوتر نوشته می‌شوند. این فاصله در پایتون بخشی از ساختار برنامه است؛ معمولاً از ۴ فاصله استفاده می‌کنیم.

    درست ✅

    correct_indent.py
    age = 15

if age >= 13:
    print("Allowed")

    خطادار؛ برای مقایسه ❌

    wrong_indent.py
    age = 15

if age >= 13:
print("Allowed")
    کد سمت دوم را عمداً خطادار نوشته‌ایم.

    دستور print() باید داخل بدنهٔ if تورفتگی داشته باشد.

    ۶. استفاده از else

    خطاها؛ سرنخ‌های پایتون

    وقتی برنامه درست پیش نمی‌رود، پیام خطا یک بن‌بست نیست؛ راهنمایی است که به ما می‌گوید کجا را بررسی کنیم.

    SyntaxError Runtime Error Logical Error Debugging
    در این بخش انواع خطا خطاهای رایج خواندن پیام خطا آزمایشگاه پروژه
    یک برنامه‌نویس خوب کسی نیست که هرگز خطا نکند.

    برنامه‌نویس خوب یاد می‌گیرد خطا را بخواند، علتش را پیدا کند، راه‌حل را آزمایش کند و از آن تجربه بسازد.

    ۱. خطا چیست؟

    گاهی کدی که نوشته‌ایم اجرا نمی‌شود؛ گاهی در میانهٔ اجرا متوقف می‌شود؛ و گاهی بدون هیچ پیام خطایی اجرا می‌شود اما جواب نادرستی می‌دهد. هر سه وضعیت نیازمند بررسی‌اند.

    ۲. سه دستهٔ مهم خطا

    خطای نگارشی

    ساختار کد با قوانین پایتون هماهنگ نیست؛ مانند نبستن پرانتز یا ننوشتن دونقطه پس از شرط.

    Syntax Error
    خطا هنگام اجرا

    کد از نظر ساختار پذیرفته شده، اما هنگام اجرا به مشکلی مثل تقسیم بر صفر یا مقدار نامعتبر می‌رسد.

    Runtime Error / Exception
    خطای منطقی

    برنامه اجرا می‌شود، اما محاسبه یا تصمیم آن با هدف ما مطابقت ندارد.

    Logical Error
    یک تفاوت مهم

    NameError، ValueError و نمونه‌های مشابه، خطاهای هنگام اجرا هستند. اما «خطای منطقی» معمولاً نام یک استثنای پایتون نیست و ممکن است هیچ پیامی نشان ندهد.

    ۳. خطای SyntaxError

    وقتی قوانین نوشتن کد رعایت نشوند، پایتون نمی‌تواند آن را درست تفسیر کند. در مثال زیر پرانتز بسته نشده است.

    خطادار · missing_colon.py
    age = 18

    print("Adult")

    import turtle

def read_sides():
    while True:
        try:
            sides = int(input("Sides (3-10): "))
        except ValueError:
            print("Enter a whole number.")
            continue

        if 3 <= sides <= 10:
            return sides

        print("Choose a number from 3 to 10.")

def draw_flower(pen, petals, color):
    pen.pencolor(color)

    for i in range(petals):
        pen.circle(45)
        pen.right(360 / petals)

def draw_polygon(pen, sides, radius, color):
    pen.penup()
    pen.goto(0, -radius)
    pen.setheading(0)
    pen.pendown()

    pen.pencolor(color)
    pen.fillcolor(color)

    pen.begin_fill()
    pen.circle(radius, steps=sides)
    pen.end_fill()

sides = read_sides()
palette = input(
    "Palette (mint/blue/coral): "
).strip().lower()

if palette == "blue":
    petal_color = "#79b8ff"
    center_color = "#ffab79"
elif palette == "coral":
    petal_color = "#ff8874"
    center_color = "#91e2cd"
else:
    petal_color = "#32d4bd"
    center_color = "#ffd343"

screen = turtle.Screen()
screen.title("Geometry Garden")
screen.bgcolor("#10243a")

pen = turtle.Turtle()
pen.speed(0)
pen.pensize(2)

draw_flower(pen, sides * 2, petal_color)
draw_polygon(pen, sides, 70, center_color)

pen.hideturtle()

turtle.done()

    import json

FILE_NAME = "scores.json"

def load_scores():
    try:
        with open(FILE_NAME, "r", encoding="utf-8") as file:
            scores = json.load(file)
    except FileNotFoundError:
        return {}
    except json.JSONDecodeError:
        print("Invalid JSON file; no changes were made.")
        return None
    except OSError:
        print("The score file could not be read.")
        return None

    if not isinstance(scores, dict):
        print("Unexpected file format.")
        return None

    for name, score in scores.items():
        valid_name = isinstance(name, str) and name.strip()
        valid_score = (
            type(score) in (int, float)
            and 0 <= score <= 20
        )

        if not valid_name or not valid_score:
            print("Invalid score data; no changes were made.")
            return None

    return scores

def ask_score():
    while True:
        try:
            score = float(input("Score (0-20): "))
        except ValueError:
            print("Enter a valid number.")
            continue

        if 0 <= score <= 20:
            return score

        print("Score must be between 0 and 20.")

def save_scores(scores):
    with open(FILE_NAME, "w", encoding="utf-8") as file:
        json.dump(
            scores,
            file,
            ensure_ascii=False,
            indent=2
        )

def main():
    scores = load_scores()

    if scores is None:
        return

    name = input("Student name: ").strip()

    if not name:
        print("Name cannot be empty.")
        return

    scores[name] = ask_score()

    try:
        save_scores(scores)
    except OSError:
        print("Could not save the score file.")
        return

    average = sum(scores.values()) / len(scores)

    print("Saved:", name, scores[name])
    print("Students:", len(scores))
    print("Average:", average)

main()

      برنامه‌نویسی؛ از پرسیدن شروع کن
    
    

    
    
      پشت یک بازی، دوربین گوشی یا صفحهٔ ورود به حساب،
      مجموعه‌ای از دستورها و تصمیم‌ها قرار دارد.
      یاد می‌گیریم این دستورها از کجا می‌آیند.
    
    

    
    
      برنامه‌نویسی
      برنامه
      برنامه‌نویس
      حل مسئله
    
    
  
    

  
    
    
    
      
        وقتی در یک بازی روی «شروع» می‌زنی، کامپیوتر
        از کجا می‌داند بعدش چه کار کند؟
      

      
    
        کسی از قبل رفتار مورد انتظار را به شکل دستورهای قابل‌اجرا
        طراحی و پیاده‌سازی کرده است.
      
    
    
    

    
    ۱. برنامه‌نویسی چیست؟
    

    
    
      برنامه‌نویسی یعنی طراحی و نوشتن دستورهایی که کامپیوتر
      بتواند آن‌ها را اجرا کند. با کمک یک زبان برنامه‌نویسی،
      به کامپیوتر می‌گوییم چه کاری انجام دهد
      و در شرایط مختلف چگونه رفتار کند.
    
    

    
    
      
    
        مثال: باز کردن دوربین
        
    با لمس دکمه، برنامه فرمان می‌دهد دوربین فعال شود.
    
      
    

      
    
        مثال: ورود به حساب
        
    
          برنامه اطلاعات واردشده را بررسی می‌کند و
          بر اساس نتیجه، تصمیم می‌گیرد.
        
    
      
    
    
    

    
    ۲. برنامه چیست؟
    

    
    
      برنامه مجموعه‌ای از دستورهای قابل‌اجراست
      که به کامپیوتر می‌گوید چه کارهایی انجام دهد.
      مثلاً یک برنامهٔ ماشین‌حساب ساده می‌تواند:
    
    

    
      
      
    1. عدد اول را دریافت کند.
      2. 
      
    2. عدد دوم را دریافت کند.
      3. 
      
    3. دو عدد را با هم جمع کند.
      4. 
      
    4. نتیجه را نمایش دهد.
      5. 
    
    

    
    
      تفاوت این دو واژه
      
    
        «برنامه‌نویسی» فرایند طراحی و ساخت است؛
        «برنامه» چیزی است که ساخته و اجرا می‌شود.
      
    
    
    

    
    ۳. برنامه‌نویس کیست؟
    

    
    
      برنامه‌نویس کسی است که برنامه‌های کامپیوتری را
      طراحی، پیاده‌سازی، آزمایش و اصلاح می‌کند.
      او باید مسئله را بفهمد، برایش راه‌حل پیدا کند،
      مراحل حل را مشخص کند و در پایان، نتیجه را بررسی کند.

      را هم پرورش می‌دهیم.
    
    

    
    
      ایدهٔ مهم این فصل

        هم به تو کمک می‌کند.

      ۱۶. الگوریتم چیست؟
    
    

    
    
      الگوریتم مجموعه‌ای از مراحل منظم برای حل یک مسئله
      یا انجام یک کار است. این مراحل الزاماً کد نیستند؛
      ممکن است ابتدا آن‌ها را با زبان ساده بنویسیم.

        و چه زمانی کار تمام می‌شود».

      6.

    ۱۸. چرا دستور دقیق اهمیت دارد؟

      4. 
      
    4. آرد را اضافه کن.
      5. 
      
    5. مواد را مخلوط کن.
      6. 
      
    6. قالب را آماده کن.
      7. 
      
    7. مواد را در قالب بریز.

      تفکر الگوریتمی یعنی یک مسئله را بشناسیم،
